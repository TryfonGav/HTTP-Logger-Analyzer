# AI journal

AI assistance is permitted on this project on the condition that every use is recorded here
(agreement with the supervisor, dated _YYYY-MM-DD_; written confirmation stored in the shared
Drive folder).

**Rules I follow**

1. One entry per session in which an AI tool influenced code, design, documentation or planning.
2. Record what I kept, what I changed and how I verified it.
3. Link the commit, PR or issue the output ended up in.
4. Label the PR `ai-assisted`.

## Entry template

| Field | Entry |
| --- | --- |
| Date | YYYY-MM-DD |
| Tool / model | e.g. Claude (Anthropic), ChatGPT, Copilot |
| Purpose | What I needed help with |
| Prompt summary | What I asked, in brief |
| Output used | What I took from the answer |
| My changes | What I rewrote, rejected or extended, and why |
| Verification | How I checked it was correct (build, tests, docs, supervisor) |
| Where it ended up | Commit / PR / issue / file |
